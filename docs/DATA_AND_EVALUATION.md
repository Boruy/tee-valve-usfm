# 数据与评估协议

## 已有数据

主集位于 `dataset/TEEdataset/`。`preprocessed_short_output/short` 和 `preprocessed_short_output_TEST5` 分别为短轴（SAX）训练与测试文件夹；`preprocessed_long_output_v2.0/long` 和 `preprocessed_long_test_v2.0/long` 分别为长轴（LAX）训练与测试文件夹。`crop_long/` 与 `crop_long_test/` 是长轴替代处理版本，不作为独立病例计数，也不与主集混合评估。

每个样本由 `*_img.nii.gz` 和 `*_label.nii.gz` 配对。主集数组为 `H × W × T`，当前将第三维当作帧顺序；NIfTI 头并未提供可靠的时间采样信息。掩膜以前景 `>0` 二值化，兼容标注值 `1` 和 `65535`。必须逐例核实图像、标签维度和仿射矩阵的一致性。

已审计的主集：SAX 训练 46 条/5,390 帧、测试 5 条/465 帧；LAX 训练 40 条/4,440 帧、测试 4 条/414 帧。全部 95 条主集图像与标签尺寸一致；SAX 训练第 27 例的仿射矩阵不一致。SAX 训练第 24 例标签文件名为 `*_img_label.nii.gz`，配对器已兼容。LAX 训练第 2/11 例以及第 3/8 例各存在字节相同的图像、不同的标签，训练前须人工复核。SAX 测试第 3 条序列有一个空标注帧，邻近帧有较大标注，须核查是否漏标。

## 正式研究前的限制

- 现有文件名和文件夹不能证明患者级训练/测试隔离，须获取去标识化患者映射并重新冻结划分。
- 有原图与处理版重复、标注编码混用以及个别配准/标注冲突风险；使用 `audit_dataset.py` 生成清单后逐例处理。
- 未确认帧顺序和标注语义前，时序指标仅属探索；没有帧率时不可宣称物理速度。
- 临床有效性或模型之间的公平排名需要统一患者、输入分辨率、提示预算和数据清理规则。
